# HbA1c ANCOVA in R — university coursework reanalysis

**Independent educational reanalysis of a supplied course dataset; not original clinical-trial evidence.** The file `data/hb.csv` is not synthetic. Its research provenance and measurement units are not independently documented in the CSV. The original university assignment describes a two-group parallel comparison with HbA1c measured at baseline and follow-up.

## Research question

Is follow-up HbA1c different between groups A and B after adjustment for baseline HbA1c?

## Methods demonstrated

- Data validation and correct **semicolon + decimal-comma** import with `read.csv2()`.
- Summary statistics and exploratory visualisation with `ggplot2`.
- Linear regression / ANCOVA: `lm(hb1 ~ groupe + hb0)`.
- Interpretation of coefficients and 95% confidence intervals.
- Model diagnostics: residual/fitted plots, QQ-plot, scale-location, leverage/Cook's distance.
- Common-slope assumption using baseline-by-group interaction.
- Heteroskedasticity-robust HC3 standard errors, calculated in base R.
- Welch and Wilcoxon rank-sum analyses of change scores (exploratory).
- Scientific report generated by **Quarto**.

## Independently checked results

After correctly parsing decimal commas, the dataset has **75 observations**, **37 in group A** and **38 in group B**, with **no missing values or repeated IDs**. The baseline-adjusted group-B coefficient is approximately **−1.15** (95% CI **−1.58 to −0.72**, p < 0.001). These values were independently cross-checked in Python with an equivalent ordinary least squares model; they should be reproduced by running the R script.

An earlier version of the coursework imported decimal-comma measurements as much larger numbers, producing misleading results. This version documents and corrects that issue. The dataset alone is not enough to substantiate a causal intervention claim.

## Run locally

From the project root in RStudio or an R terminal:

```r
install.packages("ggplot2") # only needed once
source("R/analysis.R")
```

Then render the report with Quarto (Quarto must be installed):

```bash
quarto render report.qmd
```

The analysis creates figures and tables inside `outputs/`.
